# 🚀 DeepSeek Windows 全局输入框翻译助手 使用文档

这是一个基于 **AutoHotkey v2** 与 **Python (FastAPI)** 构建的本地化全局翻译微服务工具。它可以在 Windows 系统的**任意**文本输入框中，通过快捷键丝滑地将中文替换为地道、专业的英文，同时无损保护你的系统剪贴板历史。

## ⚙️ 一、 核心功能与快捷键

在后台服务运行期间，你可以在任何聊天窗口、代码编辑器、浏览器或 Word 文档中使用以下快捷键：

| 快捷键 | 功能说明 | 适用场景 |
| --- | --- | --- |
| `Ctrl + Shift + 6` | **翻译选中内容**<br>

<br>手动用鼠标选中文本后按下，仅翻译并替换高亮部分。 | 输入框内中英文混杂，只想翻译特定一两句话时。 |
| `Ctrl + Shift + 7` | **全选并翻译**<br>

<br>无需选中，按下后自动全选当前输入框内的所有文字并进行翻译替换。 | 输入框内纯中文，希望一步到位“盲操”时。 |

> **💡 核心体验提示：**
> 翻译过程中，系统鼠标旁会短暂浮现提示。得益于剪贴板隔离技术，翻译完成并粘贴后，你原本按 `Ctrl+C` 存留在剪贴板里的图片或文字**不会被覆盖**，随时可以继续正常使用 `Ctrl+V`。

## 📝 二、 场景测试示例

由于我们在配置中深度定制了翻译风格，你可以尝试输入以下不同领域的中文来测试它的表现：

* **场景 1：学术与外刊（考研/阅读）**
* *输入：* “这项研究表明，气候变化对全球经济复苏有着深远且不可逆的负面影响。”
* *效果：* 将呈现出接近《科学美国人》或《哈佛商业评论》的严谨句式与高级词汇。


* **场景 2：系统配置与排障**
* *输入：* “不改密码，需要在 msconfig 里修改 Windows 启动设置。”
* *效果：* 将准确使用 `msconfig`、`boot options` 等系统级原生词汇，而非生硬的直译。


* **场景 3：网络工程与路由配置**
* *输入：* “如何在主路由上隔离 LAN2 接口，从而绕过旁路由的代理服务？”
* *效果：* 将精准运用 `bypass router`, `interface isolation`, `proxy` 等网络专业术语。



## 🛠️ 三、 配置文件修改 (.env)

本工具的核心配置已与代码完全剥离。如果需要修改 API 密钥或调整翻译风格，只需用记事本打开项目根目录下的 `.env` 文件。

```ini
# DeepSeek API 身份验证
DEEPSEEK_API_KEY="sk-你的真实密钥"

# 本地通信端口 (如遇端口占用，可修改此处，并同步修改 AHK 源码)
SERVER_PORT=8989

# 系统提示词 (System Prompt)
# 你可以在这里随时修改翻译助手的“人设”和“专业领域”
SYSTEM_PROMPT="你是一个专业的英文翻译助手......(省略)"

```

*注：修改 `.env` 文件后，必须重启后台 Python 服务才能生效。*

## 🔄 四、 启动与开机自启

**日常启动：**
每次使用前，只需双击运行项目文件夹中的 `start.vbs` 文件。没有任何弹窗和黑框，当右下角任务栏出现绿色的 AHK 图标（含有白色的 `H` 字样）时，即代表 Python 引擎与 AHK 监听均已在后台静默就绪。

**设置开机自启（推荐）：**

1. 右键点击 `start.vbs`，选择 **“创建快捷方式”**。
2. 按下键盘上的 `Win + R`，输入 `shell:startup` 并回车。
3. 将刚才创建的快捷方式拖入弹出的文件夹中即可。

## 🔍 五、 常见问题与排障指南

**Q1: 快捷键按下去没反应？**

* **检查:** 确认右下角是否有绿色的 AHK 图标。如果没有，说明 `start.vbs` 未能成功拉起客户端，请手动双击 `client.ahk` 尝试。
* **冲突:** 可能是 `Ctrl+Shift+6/7` 被其他软件（如输入法、录屏软件）全局占用。可以右键 AHK 图标选择 `Edit Script` 修改快捷键映射。

**Q2: 提示“翻译失败，请检查后台 Python 服务或网络”**

* **原因 1:** DeepSeek 账户余额不足，或 `.env` 中的 API Key 填写错误（注意保留英文双引号）。
* **原因 2:** Python 后台服务死机。请打开任务管理器，结束所有 `python.exe` 进程，然后重新运行 `start.vbs`。

**Q3: 翻译结果经常少字或者变成了乱码？**

* 这通常是由于你的输入法开启了“中文状态下输入英文标点”或系统剪贴板读取过快。可以打开 `client.ahk`，适度调大 `Sleep 50` 和 `Sleep 150` 的毫秒数，给系统留出更多的缓冲时间。
